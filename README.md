# Security-dashboard-backend
Security Dashboard Backend API built with Node.js, Express, MongoDB Atlas, and Mongoose for monitoring and managing security logs and incidents.
Features:
MongoDB Atlas integration
RESTful API endpoints
Security log management
Environment variable configuration
Modular MVC architecture
Technologies Used
Node.js
Express.js
MongoDB Atlas
Mongoose
dotenv
CORS
Getting Started
Clone the repository
Install dependencies
npm install
